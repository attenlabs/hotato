# Backlog

Goal: every capability that voice-agent teams already rely on in testing and monitoring tools.
Ranked. The builder takes the first item not marked `[x]`. The weekly scorecard may reorder it.

1. Simulated voice callers: many personas, real phone calls through a telephony provider, generated from the agent's prompt
2. Production call monitoring plus alerts (Slack, PagerDuty, webhook)
3. AI-judged plus custom metrics, next to the timing metrics
4. Tracing and sessions on OpenTelemetry, with cost and latency analytics
5. Datasets, experiments, and side-by-side prompt versions
6. A human review and annotation queue
7. Dashboards and a team workspace in the hosted service
8. Integrations: LiveKit, Pipecat, Twilio, a public API, and Python and JS SDKs
9. Self-host with docker-compose, plus the hosted cloud
10. Load tests and red-team or compliance packs
11. Instant shareable first result on hotato.dev
12. Public turn-taking leaderboard
